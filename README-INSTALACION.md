# Rabbit Garage Mecánica – V2 Android

## Publicar como aplicación instalable
1. Crear un repositorio nuevo en GitHub (por ejemplo `rabbit-garage-app`).
2. Subir todo el contenido de esta carpeta a la rama `main`, incluyendo `.github/workflows/pages.yml`.
3. En GitHub: **Settings → Pages → Source: GitHub Actions**.
4. Esperar a que termine el workflow **Deploy Rabbit Garage to GitHub Pages**.
5. Abrir la URL que muestra el workflow desde Chrome en Android.
6. En Chrome elegir **Instalar aplicación** / **Agregar a pantalla de inicio**.

La PWA necesita HTTPS para que el Service Worker y la instalación funcionen correctamente.
